## Description (4,000 characters max)

### Current Length: 891 characters

Elevator System brings modern, real-time elevator control to your mobile device. Designed for building management and maintenance teams, this app provides instant access to elevator operations with live status updates.

KEY FEATURES

Real-Time Status
Monitor elevator position and movement in real-time with live GraphQL subscriptions. See the current floor, direction, and next destination instantly without refreshing.

Priority System
Set request priorities to ensure critical calls are handled first:
- Normal priority for routine use
- High priority for time-sensitive requests
- Emergency priority for immediate response

Visual Floor Selection
Intuitive grid interface showing all 20 floors with color-coded status:
- Blue highlights indicate current elevator position
- Green shows active floor requests
- White represents available floors

Active Request Tracking
View all pending elevator requests in real-time, including floor numbers and priority levels. Stay informed about system activity and queue status.

Reliable Connection
Built on enterprise-grade WebSocket technology for instant updates. Automatic reconnection ensures continuous monitoring even with network interruptions.

TECHNICAL HIGHLIGHTS
- GraphQL subscriptions for push-based updates
- WebSocket connectivity for real-time data
- Clean, modern interface following iOS design guidelines
- Optimized for both iPhone and iPad

IDEAL FOR
- Building management teams
- Facility maintenance staff
- Property managers
- System administrators

### Minimum Privacy Policy Requirements

Your privacy policy must address:

1. **Data Collection**
   - What data is collected (if any)
   - How data is used
   - Third-party data sharing (if applicable)

2. **Network Requests**
   - Backend connection to backend.adapt-llc.com
   - GraphQL API usage
   - WebSocket connections

3. **User Information**
   - Does NOT collect personal information
   - Does NOT require user accounts
   - Does NOT track user behavior

### Sample Privacy Policy Text

```markdown
# Privacy Policy for Elevator System

Last updated: [DATE]

## Overview
Elevator System is a facility management application that connects to building elevator systems for monitoring and control.

## Data Collection
This app does NOT collect, store, or transmit any personal user information.

## Network Connections
The app connects to your organization's elevator control backend for real-time status updates and control operations. All data transmitted is related to elevator system operations only (floor numbers, elevator status, and control commands).

## Third-Party Services
This app does not integrate with any third-party analytics, advertising, or tracking services.

## Data Storage
No user data is stored on the device or on external servers.

## Children's Privacy
This app does not knowingly collect information from children under 13.

## Changes to Privacy Policy
We may update this policy from time to time. Continued use of the app constitutes acceptance of any changes.

## Contact
For questions about this privacy policy, contact: [YOUR EMAIL]
```
